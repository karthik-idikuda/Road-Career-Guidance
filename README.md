# Road Career Guidance

AI-powered career roadmap platform that generates personalized learning paths and skill recommendations based on career goals.

## Features

- Career goal assessment questionnaire
- Personalized learning path generation
- Skill gap analysis
- Course and resource recommendations
- Progress milestone tracking

## Tech Stack

HTML, CSS, JavaScript

## Getting Started

### Prerequisites

- Node.js 18+
- npm

### Installation

```bash
git clone https://github.com/karthik-idikuda/Road-Career-Guidance.git
cd Road-Career-Guidance
Open index.html in a browser.
```

### Usage

```bash
Open index.html in any modern browser.
```
